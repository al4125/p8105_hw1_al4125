``` r
# Create data frame
set.seed(1234)

p2_df =  tibble(
  rand_sample = rnorm(10), 
  log_vector = rand_sample > 0,
  char_vector = c("x", "y", "z", "a", "b", "c", "d",   "e", "f", "g"),
  factor_vector = factor(c(1, 2, 3, 1, 2, 3, 1, 2, 3, 1))
)
```

When taking the mean, it worked for the random sample and logical
vector, which were -0.38 and 0.4 respectively. It did not work for the
character vector and factor vector, which returned NA since they are not
numeric or logical variables.

``` r
# Mean after using as.numeric() on variables
as.numeric(pull(p2_df, log_vector))
as.numeric(pull(p2_df, char_vector))
as.numeric(pull(p2_df, factor_vector))
```

When using as.numeric, the logical vector was converted to zeros and
ones, so its mean could be calculated. The character vector returned NA
since it could not be converted to numbers, and therefore the mean was
not able to be calculated. The mean was also not calculated for the
factor vector since its values are categorical, even though as.numeric
converted the factor levels to numbers.
